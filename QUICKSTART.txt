⚡ COSA FA OGNI COMPONENTE:

Backend Flask (app.py)
  → Riceve dati dal voicebot Wildix
  → Salva i dati nel database PostgreSQL
  → Integra con Google Sheets (callback list)
  → Fornisce API REST al frontend

Frontend Dashboard (index.html + script.js)
  → Mostra lista callback in sospeso
  → Bottone "Completa" per segnalinformazione che hai richiamato il cliente
  → Mostra prenotazioni odierne
  → Integra Google Calendar

Database (PostgreSQL)
  → Salva callback richieste
  → Salva prenotazioni
  → Salva info operatrici

Google Sheets
  → Lista callback (gli operatori vedono qui)

Google Calendar
  → Slot disponibili per le prenotazioni

═══════════════════════════════════════════════════════════════════════════

🎯 FLUSSO PRATICO:

1. Cliente chiama il numero del Centro Anxur
2. Wildix PBX risponde con voicebot AI
3. Voicebot chiede: "Desideri prenotare?"
4. Cliente racconta i dati (nome, tipo analisi, ecc.)
5. Voicebot invia HTTP POST al backend (con i dati)
6. Backend salva in database + Google Sheets
7. Dashboard mostra il callback nell'app
8. Operatrice vede nuovo callback, chiama il cliente
9. Quando risponde il cliente, operatrice segna "Completato"
10. Riga viene cancellata da Google Sheets
